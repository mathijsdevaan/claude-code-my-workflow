# Workflow Quick Reference

**Model:** Contractor (you direct, Claude orchestrates)

---

## The Loop

```
Your instruction
    ↓
[PLAN] (if multi-file or unclear) → Show plan → Your approval
    ↓
[EXECUTE] Implement, verify, done
    ↓
[REPORT] Summary + what's ready
    ↓
Repeat
```

---

## I Ask You When

- **Design forks:** "Option A (fast) vs. Option B (robust). Which?"
- **Code ambiguity:** "Spec unclear on X. Assume Y?"
- **Replication edge case:** "Just missed tolerance. Investigate?"
- **Scope question:** "Also refactor Y while here, or focus on X?"

---

## I Just Execute When

- Code fix is obvious (bug, pattern application)
- Verification (tolerance checks, tests, compilation)
- Documentation (logs, commits)
- Plotting (per established standards)
- Deployment (after you approve, I ship automatically)

---

| Score | Action |
|-------|--------|

## Non-Negotiables

- **Paths:** all R paths relative to repository root; LaTeX compiles with `TEXINPUTS=../Preambles` (XeLaTeX only)
- **Seeds:** `set.seed()` called once at top of every stochastic script, YYYYMMDD format
- **Figures:** `ggsave()` with `bg = "transparent"` and explicit dimensions (12 × 5 in for Beamer); `theme_custom()` from `.claude/rules/r-code-conventions.md`
- **Colors:** Berkeley themes — teaching: BerkeleyBlue `#003262`, Medalist `#C4820E`, FoundersRock `#3B7EA1`, CaliforniaGold `#FDB515`; academic: AccentRed `#A12830`, FooterGray `#3F3F3F`, OliveRule `#9B8B5A` (see `Preambles/`); R plotting palette pinned in `.claude/rules/r-code-conventions.md`
- **Tolerances:** point estimates 1e-6, standard errors 1e-4, coverage rates ± 0.01 (see `quality-gates.md`)

---

## Preferences

**Visual:** figures generated by scripts only (never hand-edited); transparent backgrounds; regenerate stale figures before recompiling slides
**Reporting:** concise bullets with quality scores; details on request
**Session logs:** Always (post-plan, incremental, end-of-session)
**Replication:** strict — flag near-misses at the tolerance boundary for investigation rather than passing them silently

---

## Exploration Mode

For experimental work, use the **Fast-Track** workflow:
- Work in `explorations/` folder
- 60/100 quality threshold (vs. 80/100 for production)
- No plan needed — just a research value check (2 min)
- See `.claude/rules/exploration-fast-track.md`
