# Single Source of Truth: Enforcement Protocol

**The Beamer `.tex` file is the authoritative source for ALL content.** Everything else is derived.

## The SSOT Chain

```
Beamer .tex (SOURCE OF TRUTH)
  ├── Bibliography_base.bib (shared)
  └── Figures/LectureN/* — generated by R scripts (derived)

NEVER edit derived artifacts independently.
ALWAYS propagate changes from source → derived.
```

---

## Figure Freshness (MANDATORY)

- Every figure included via `\includegraphics` must come from a generating
  script (R or TikZ source) — never edit figure files by hand
- If the generating script or analysis changed, regenerate the figure BEFORE
  recompiling the slides
- Any figure whose generating script cannot be identified is a defect: track
  down or recreate the script

---

## Derived-Format Rule

If this project later derives additional formats from the Beamer source
(HTML slides, handouts, a Quarto translation), apply the same discipline:

1. Every derived artifact is regenerated from the `.tex` source, never edited independently
2. Before committing a derived artifact, check content parity with the source:
   frame count, equations, citations, figures — nothing added, nothing dropped
3. Automate the derivation with a script checked into `scripts/`
